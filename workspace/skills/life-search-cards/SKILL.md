# 技能：生服搜索卡片数据查询助手

## 🎯 目标与触发场景

## 📂 数据源 (Data Source)
请注意所有数据都是tea-next报表，你需要用tea-open-api 技能来查询数据，不要直接用浏览器打开。

1. 卡片PV、名称
- 【综搜单列卡片列表和流量】 当需要查询综搜单列卡片有哪些，以及每个卡片的名称、流量时，需要使用此数据，数据地址为：<https://data.bytedance.net/tea-next/project/3/event-analysis/7623023825898177034?dashboardId=7623022464808780338>
- 【综搜双列卡片列表和流量】 当需要查询综搜双列卡片有哪些，以及每个卡片的名称、流量时，需要使用此数据，数据地址为：<https://data.bytedance.net/tea-next/project/3/event-analysis/7623024261434704411?dashboardId=7623022464808780338>
- 【垂搜卡片列表和流量】 当需要查询垂搜卡片有哪些，以及每个卡片的名称、流量时，需要使用此数据，数据地址为：<https://data.bytedance.net/tea-next/project/3/event-analysis/7623024398626357798?dashboardId=7623022464808780338>

2. 整体首刷数据，这里只有分场景整体的首刷耗时数据，没有每个卡片的首刷耗时数据
- 【综搜双列性能】 当需要查询综搜双列的首刷耗时，需要使用此数据，数据地址为：<https://data.bytedance.net/tea-next/project/3/event-analysis/7489014430986928667?dashboardId=7440012806835700251>
- 【综搜单列性能】 当需要查询综搜单列的首刷耗时，需要使用此数据，数据地址为：<https://data.bytedance.net/tea-next/project/3/event-analysis/7495650565506990601?dashboardId=7440012806835700251>
- 【垂搜性能】 当需要查询垂搜的首刷耗时，需要使用此数据，数据地址为：<https://data.bytedance.net/tea-next/project/3/event-analysis/7440020214005924362?dashboardId=7440012806835700251>

3. 卡片首刷耗时，这里是含有指定卡片的首刷耗时
- 【综搜单列卡片首刷耗时】 当需要查询综搜单列卡片的首刷耗时，需要使用此数据，这里包含了每一个卡片的首刷耗时数据，数据地址为：<https://data.bytedance.net/tea-next/project/3/event-analysis/7440013053624353317?dashboardId=7440012806835700251>
- 【综搜双列卡片首刷耗时】 当需要查询综搜双列卡片的首刷耗时，需要使用此数据，这里包含了每一个卡片的首刷耗时数据，数据地址为：<https://data.bytedance.net/tea-next/project/3/event-analysis/7519741588869513754?dashboardId=7440012806835700251>
- 【垂搜卡片首刷耗时】 当需要查询垂搜卡片的首刷耗时，需要使用此数据，这里包含了每一个卡片的首刷耗时数据，数据地址为：<https://data.bytedance.net/tea-next/project/3/event-analysis/7457889199421653513?dashboardId=7440012806835700251>

查询数据需要注意：
- 这些报表都有默认的筛选条件，比如日期范围，你可以根据查询需要调整这些筛选条件
- 不要缓存任何数据或者从之前对话中提取任何数据，每当用户发起查询要求，你都要重新查询
- 查询到的所有耗时数据的单位都是毫秒，你也需要以毫秒输出
- 上述所有报表都是按天聚合的，返回结果中的每一项都是某一天的数据

## 业务知识
- 综搜分为单列和双列两种，单列也叫大卡，双列也叫小卡
- 垂搜可以细分为分为独立入口和垂搜两种，其中独立入口也叫商搜
- 垂搜的”poi卡“，有”店挂图“ 和 ”店挂文“两种形式

## 数据输出格式

如果没有任何输出要求，就按如下表格格式输出，其中内容的每一行就是一个指标：

| 指标 | 当日值 | 日环比 | 周同比 |
| :--- | :--- | :--- | :--- |
| ... | ... | ... | ... |

## 日报输出格式

如果是输出日报，需要输出”性能大盘“和”流量大盘“两个表格。这两个表格的内容定义如下：

流量大盘，输出格式和内容为：
| 指标 | 当日值 | 日环比 | 周同比
| :--- | :--- | :--- | :--- |
| 综搜单列卡片PV总和 | ... | ... | ... |
| 综搜双列卡片PV总和 | ... | ... | ... |
| 垂搜卡片PV总和 | ... | ... | ... | ... |

注意流量大盘是按卡片分的，统计时候需要将当天所有卡片的流量加起来。

性能大盘，输出表格格式和内容为:
| 指标 | 当日值 | 日环比 | 周同比 |
| :--- | :--- | :--- | :--- |
| 综搜双列性能 | ... | ... | ... |
| 综搜单列性能 | ... | ... | ... |
| 垂搜性能 | ... | ... | ... |

注意性能大盘是AVG耗时，单位是毫秒。
