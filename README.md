## 关于本仓库
这个仓库是自己实现一个类似 open-claw 的 agent，可以实现其主要功能，能作为一个 agent 自主规划、执行任务。

## 技术栈
- 主要编程语言：**TypeScript**（项目涉及大量消息格式、工具 schema、API 响应等结构化数据，类型安全能显著减少 bug）

## 功能

### 基础能力（主链路，优先实现）

1. **Loop** — 规划-执行-观察循环，直到任务完成
   - 终止条件：任务完成、模型判断无法继续、用户中断
   - 异常处理：执行失败时重试或换策略，单次循环最大步数限制
   - 超时控制：单步执行和整体任务的超时机制
2. **Model IO + Prompt** — 调用大模型，管理提示词
   - Prompt 管理：使用模板和上下文构造提示词
   - Model 调用：发送 prompt，获取响应
   - **流式输出**：一开始就支持 streaming，避免后期高成本改造
   - 这两个模块强耦合（prompt 构造的输出就是 Model IO 的输入），合并实现
3. **工具调用** — 脚本执行、文件读写等
   - 声明式工具注册：使用 JSON Schema 定义工具的参数和描述（类似 OpenAI function calling）
   - 工具发现：自动发现和注册可用工具
   - **安全沙箱**：工具执行需要权限控制和资源限制（这是基础能力，不是高级能力）
4. **History** — 历史消息管理
5. **上下文压缩** — 长任务导致上下文溢出时自动压缩
   - 优先级提前：主链路跑通后任务变长，上下文溢出会立刻成为瓶颈
6. **配置管理** — 模型选择、API key、工具权限等配置的统一管理

### 高级能力（基础能力完成后）
1. **Memory** — 分层记忆系统
2. **Skill** — 技能系统，支持可插拔的专项能力
3. **聊天工具** — 对接飞书、钉钉等
4. **RAG** — 检索增强生成

## 开发顺序

基础能力按依赖顺序实现：Loop → Model IO + Prompt → 工具调用 → History → 上下文压缩 → 配置管理。每个能力实现并可用后再做下一个。高级能力在基础能力之上构建。
