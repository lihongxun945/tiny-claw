## 架构设计决策

- **技术栈**：JS → TypeScript，项目涉及大量结构化数据，类型安全收益大
- **Model IO + Prompt 合并实现**：两者强耦合，分开做容易接口不匹配
- **Loop 补全异常路径**：终止条件、异常处理、超时控制
- **工具调用增加安全沙箱**：声明式 JSON Schema 注册，权限控制
- **上下文压缩提前到基础能力**：主链路跑通后立即需要
- **新增配置管理**：作为基础能力
- **流式输出一开始就支持**：后期改造成本高

## 开发顺序确定

Loop → Model IO + Prompt → 工具调用 → History → 上下文压缩 → 配置管理 → 高级能力
