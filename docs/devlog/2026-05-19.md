## 工具调用 + 网络搜索实现

实现了工具调用框架和第一个工具（网络搜索），主循环升级为 Agent Loop。

### 新增/改动文件

- `src/types.ts` — 扩展 ContentBlock（TextBlock/ToolUseBlock/ToolResultBlock）、ToolDefinition、ThinkingDelta、ChatResponse
- `src/client.ts` — 支持 tools 参数、tool_use 流式解析、thinking_delta 过滤、返回结构化 ChatResponse
- `src/tools.ts` — 新建，ToolRegistry 工具注册中心
- `src/search.ts` — 新建，DuckDuckGo 搜索工具（免 API key）
- `src/index.ts` — 主循环改造为 Agent Loop：tool call → execute → feedback 循环

### 关键决策

- **参考 OpenClaw**：web_search 作为标准 function calling tool，模型自主决定何时调用
- **DuckDuckGo 作为搜索引擎**：免 API key，实现简单，降低使用门槛
- **工具注册中心模式**：ToolRegistry 支持 register/getTool/getDefinitions，方便后续扩展新工具
- **Agent Loop 雏形**：模型输出 → 可能调用工具 → 执行 → 结果反馈 → 模型继续输出，直到无工具调用

### 模型切换

- 默认模型从 claude-sonnet-4-5 改为 kimi-k2.6（火山方舟 Coding Plan 支持的模型）
- kimi-k2.6 有 thinking 输出，client.ts 已处理 thinking_delta 过滤

## 工作目录（Workspace）实现

实现了 workspace 目录结构，统一管理 tiny-claw 的所有持久化数据。

### 新增文件

- `src/workspace.ts` — workspace 初始化、身份加载、system prompt 构建
- `workspace/identity.md` — 身份设定示例文件
- `workspace/config.example.json` — 新位置配置模板

### 改动文件

- `src/types.ts` — Config 增加 workspacePath、systemPrompt 字段
- `src/config.ts` — loadConfig 改为接收 workspacePath 参数，从 workspace/config.json 读取
- `src/client.ts` — chat 方法增加 systemPrompt 参数，支持注入 system prompt
- `src/index.ts` — 解析 --workspace CLI 参数，启动时初始化 workspace，传入 system prompt
- `config.example.json` — 添加注释，指向 workspace/config.json
- `.gitignore` — 忽略 workspace/ 下的敏感/运行时文件
- `docs/architecture.md` — 新增工作目录结构说明、workspace.ts 模块、身份注入等章节

### Workspace 结构

```
workspace/
├── config.json        # 配置（API key、模型等）
├── identity.md        # 身份设定（注入 system prompt）
├── skills/            # 自定义技能（预留）
├── memory/            # 跨会话记忆（预留）
├── history/           # 对话历史（预留）
└── logs/              # 执行日志（预留）
```

### 关键决策

- **workspace 路径可配置**：CLI 参数 --workspace 或 TINY_CLAW_WORKSPACE 环境变量，默认 ./workspace
- **identity.md 独立于配置**：自然语言身份设定不与 JSON 配置混在一起，保持可读性
- **文件类型按用途区分**：结构化数据用 JSON（config.json），人类/模型阅读用 Markdown（identity.md、skills/*.md、memory/*.md）
- **system prompt 运行时构建**：内置默认 prompt + identity.md（可选），灵活组合

## 持久化记忆系统

实现了工具驱动的跨会话记忆系统，agent 可以自主记住和回忆用户信息。

### 新增文件

- `src/memory.ts` — 记忆存储（saveMemory、appendMemory、loadAllMemories）+ 两个工具定义

### 改动文件

- `src/workspace.ts` — buildSystemPrompt 增加"长期记忆"章节，启动时加载所有 memory/*.md
- `src/index.ts` — 注册 memory_save、memory_append 两个新工具
- `docs/architecture.md` — 新增记忆系统设计决策章节、memory.ts 模块、记忆工具表格

### 设计

- **读写方式**：memory_save（写入/覆盖）和 memory_append（追加）两个工具，模型自主调用
- **存储格式**：`workspace/memory/<name>.md`，纯 Markdown
- **加载机制**：启动时读取所有 *.md，注入 system prompt 的"长期记忆"章节
- **安全措施**：name 参数校验，仅允许字母、数字、下划线、连字符，防止路径遍历
- **对比自动提取**：工具驱动更简单透明，模型自主决定记什么，用户可直接编辑记忆文件

### 测试结果

- 输入"请记住：我最喜欢的编程语言是 TypeScript，包管理器用 pnpm"
- 模型自动调用 memory_save，写入 workspace/memory/user-preferences.md
- 重启后询问"你还记得关于我的信息吗？"，模型正确回忆
