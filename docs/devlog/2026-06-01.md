# 2026-06-01

## 长期记忆管理面板

- WebUI 新增记忆管理页，支持搜索、刷新、查看、编辑、保存、删除、启用和禁用。
- Gateway 新增 `/memory` 系列 API。
- 长期记忆 frontmatter 新增 `disabled` 和 `source` 字段；禁用记忆不进入 prompt 和默认检索。
- 自动记忆写入时标记 `source: auto`。

## Ollama Web Search

- 新增 Ollama Web Search provider，默认使用 `POST https://ollama.com/api/web_search`。
- 默认搜索 provider 从 DuckDuckGo 调整为 Ollama，保留 DuckDuckGo、Brave 和 SearXNG 可切换。
- `web_search` 每次执行时动态读取最新配置，WebUI 保存 key 后无需重启。
- 配置 API 递归脱敏 key、secret、token 和 password，并避免将脱敏占位符写回磁盘。
